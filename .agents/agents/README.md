# Antigravity Agent Team

The repository is designed for Antigravity's agent-oriented workflow.

Suggested specialist roles:

- Product Architect — validates scope and architecture.
- Backend Engineer — implements domain/API/database.
- Frontend Engineer — implements contractor/supplier UX.
- QA Engineer — tests user journeys and edge cases.
- DevOps Engineer — local/prod configuration and deployment.

Do not let parallel agents independently redefine domain models or API contracts. `docs/` is the shared contract.
