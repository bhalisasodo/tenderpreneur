# Build MVP

1. Read `AGENTS.md`.
2. Read all files in `docs/`.
3. Inspect current implementation.
4. Run tests/build checks before changes.
5. Implement only the next milestone.
6. Add tests.
7. Update API/data-model documentation if contracts change.
8. Summarize changes, tests and unresolved decisions.

Never skip the source brief.
