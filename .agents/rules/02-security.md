# Security rules

- Authorize every private resource server-side.
- Enforce organisation/tenant boundaries in backend queries.
- Treat uploaded files and LLM output as untrusted.
- Never expose secrets to clients.
- Never log credentials or raw sensitive documents.
- Validate structured LLM output before persistence.
- Record audit events for material pricing decisions.
